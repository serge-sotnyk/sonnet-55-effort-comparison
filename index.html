Sonnet 5.5: reasoning levels, one game prompt

A replication of Barty-Bart/opus-55-effort-comparison with claude-sonnet-5-5 (the original is shown in this video). Each build came from the same prompt in a fresh, empty folder with a different effort level. These are experimental AI-generated games, bugs included. Desktop keyboard and mouse recommended; audio starts after a click.

Bonus: Codex with the same prompt

An additional experiment, not part of the original comparison: the same prompts run once through the Codex CLI with two OpenAI models, in fresh isolated folders without the user's instructions or memory. The original prompt ran at high, xhigh and ultra reasoning effort; the detailed Special Build prompt ran at low, as in the original experiment.

Codex reports tokens, not dollars. Input includes cached input; tokens also include the built-in approval reviewer (codex-auto-review, about 0.2M per run, up to 0.8M on the Special prompt). The cost estimate covers the main model only and uses third-party list prices (gpt-6.1-sol $2 / $0.10 cached / $10 output, gpt-6-astra $10 / $1 / $50 per 1M tokens). The weekly limit is the Codex subscription's own counter and is not comparable with Claude's. Three builds (sol · ultra, sol · xhigh, astra · xhigh) had root-absolute asset paths changed to relative ones so they run here.
